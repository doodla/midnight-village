# Data Model: Flutter UI Test Infrastructure

**Feature**: 002-flutter-ui-test-infrastructure
**Date**: 2026-03-25

This feature produces test infrastructure, not domain models. The "entities" below are the key abstractions that tests interact with.

## Key Entities

### 1. GoldenTestConfig

Configuration for deterministic golden test rendering.

```dart
/// Applied globally via flutter_test_config.dart
class GoldenTestConfig {
  /// Fixed logical screen size for all golden tests (iPhone 14)
  static const Size screenSize = Size(390, 844);

  /// Device pixel ratio for golden rendering
  static const double pixelRatio = 1.0;

  /// Platform-specific golden baseline directory
  /// e.g., test/design_system/goldens/macos/
  static String get baselineDir;
}
```

**Relationships**: Used by `flutter_test_config.dart` (global setup) and `pumpWithGolden` (per-test).

### 2. MockHttpInterceptor

Dio interceptor that replaces real HTTP calls in tests.

```dart
class MockHttpInterceptor extends Interceptor {
  /// Register a canned response for a method+path combination
  void stub(String method, String path, Response response);

  /// Register an error response
  void stubError(String method, String path, DioException error);

  /// Throws UnmockedRequestException if no stub matches
  @override
  void onRequest(RequestOptions options, RequestInterceptorHandler handler);

  /// Reset all stubs between tests
  void reset();

  /// Recorded requests for assertion
  List<RequestOptions> get requests;
}
```

**Relationships**: Injected into `ApiClient` via `Dio` interceptor chain. Used by `pumpAuthenticated` and `pumpApp` harnesses.

### 3. FakeWebSocketChannel

Simulates a WebSocket connection for testing.

```dart
class FakeWebSocketChannel implements WebSocketChannel {
  /// Inject a server-sent event (decoded as JSON map)
  void addServerEvent(Map<String, dynamic> event);

  /// Inject a raw server message
  void addServerMessage(String message);

  /// Messages sent by the client (for assertion)
  List<dynamic> get sentMessages;

  /// Simulate server closing the connection
  void closeFromServer([int? code, String? reason]);

  /// Simulate a connection error
  void simulateError(Object error);

  /// Stream of server events (consumed by production code)
  @override
  Stream<dynamic> get stream;

  /// Sink for client messages (used by production code)
  @override
  WebSocketSink get sink;
}
```

**Relationships**: Provided to game state providers via harness overrides. Used by `pumpWithGameState`.

### 4. TestHarness (Builder)

Composable test setup that configures providers for specific scenarios.

```dart
extension TestHarnessExtension on WidgetTester {
  /// Pump widget with golden test configuration
  /// Fixed size, deterministic fonts, platform-specific baselines
  Future<void> pumpWithGolden(
    Widget widget, {
    AppTokens? theme,
    Size? size,
  });

  /// Pump widget with authenticated user state
  /// Pre-loads auth providers with test user and valid tokens
  Future<void> pumpAuthenticated(
    Widget widget, {
    User? user,
    AppTokens? theme,
    List<Override>? additionalOverrides,
  });

  /// Pump widget with full game state
  /// Configures phase, players, role assignments, mock WebSocket
  Future<void> pumpWithGameState(
    Widget widget, {
    required GamePhase phase,
    required List<PlayerDisplay> players,
    User? currentUser,
    FakeWebSocketChannel? webSocket,
    AppTokens? theme,
  });

  /// Pump the full app with all mock layers for integration-style tests
  Future<void> pumpApp({
    MockHttpInterceptor? http,
    FakeWebSocketChannel? webSocket,
    String? initialRoute,
  });
}
```

**Relationships**: Composes `pumpWithTokens` (existing), `MockHttpInterceptor`, `FakeWebSocketChannel`, and Riverpod provider overrides.

### 5. FakeTimer

Controls time progression in tests for timer-dependent UI.

```dart
class FakeTimer {
  /// Current elapsed time
  Duration get elapsed;

  /// Advance time by duration, triggering any scheduled callbacks
  void advance(Duration duration);

  /// Complete the timer (jump to end)
  void complete();

  /// Whether the timer is still running
  bool get isActive;
}
```

**Relationships**: Used by `pumpWithGameState` when the game phase has a countdown timer. Replaces the production timer provider via Riverpod override.

### 6. GoldenDiffReport

Output of the visual diff comparison tool.

```
golden_diff_output/                    # Generated by tool/golden_diff_report.dart
├── report.html                        # Summary with thumbnails and navigation
├── diffs/
│   ├── mv_button_diff.png            # Pixel-diff overlay for each failure
│   ├── player_circle_diff.png
│   └── ...
└── comparisons/
    ├── mv_button_comparison.html      # Per-component side-by-side view
    └── ...
```

**Relationships**: Generated from Flutter's golden test failure output (`test/failures/`). Consumed by developers and CI artifact upload.

## State Transitions

No state machines in this feature. Test infrastructure is stateless — each test gets a fresh setup via the harness.

## Validation Rules

| Entity | Rule | Enforcement |
|--------|------|-------------|
| MockHttpInterceptor | Unmocked requests throw | `UnmockedRequestException` in `onRequest` |
| MockHttpInterceptor | Stubs reset between tests | `setUp(() => interceptor.reset())` pattern |
| FakeWebSocketChannel | Events delivered in order | `StreamController` guarantees FIFO |
| GoldenTestConfig | Screen size is fixed | Set in `flutter_test_config.dart`, cannot be overridden accidentally |
| TestHarness | User must be valid | `pumpAuthenticated` uses `User` model which enforces id>0 and non-empty name |
