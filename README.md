# Midnight Village

A party game: friends at one table use their phones for secret roles, night actions and
votes; the server runs the game. First game: One Night Ultimate Werewolf.

- `backend/`: the server (Django, DRF, Channels). Start at `backend/CLAUDE.md`.
- `frontend/`: the app (Flutter). Start at `frontend/CLAUDE.md`.
- `contract_samples/`: recorded server payloads; the only source of test fixtures.
- `docs/`: rules, screens, the look and how the work runs. Index: `docs/README.md`.

Start at `CLAUDE.md` (principles, commands, pointers). Setting up a machine:
`docs/dev/environment.md`. Where the work stands: `docs/dev/status.md`.
