# The blind test of reviewer personas (23 Nov 2026)

Method, so it can be rerun. Six personas each got `TASK.md` plus a walk-through of one game
(`walk/`: an INDEX and four contact sheets of the screens), nothing else. Each wrote a critique.
The owner then played the live app and gave 15 points; a grader matched each critique to them
(hit 1, partial 0.5). Result and recommendation: `docs/dev/running-the-work.md`, "The two critics".

The persona line each reviewer was given (the brief is `TASK.md` plus this line):

- Ruthless editor: verbatim in `.claude/agents/critic-editor.md`.
- Art director: verbatim in `.claude/agents/critic-art-director.md`.
- Awards judge: a juror for game-of-the-year awards, asks whether this is a game or an app.
- Tabletop host: someone who runs game nights and explains rules out loud every week.
- Impatient first-timer: a guest who was told "just join, it's easy" and has never played.
- Owner's eye: a stand-in trained on the owner's earlier feedback (it echoed old complaints).

The original wording of the last four was not kept; these are summaries. Next time, save all six
word for word here.
