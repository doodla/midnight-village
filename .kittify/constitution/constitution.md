## Code Quality

### Agent Review Checklist

**Common (all code):**
- Existing tests still pass — no regressions introduced
- No over-engineering — no premature abstractions or speculative features beyond what was asked
- Tests verify behavior, not implementation

**Backend:**
- No hidden information leaks in API responses, WebSocket events, or error messages
- Server-authoritative — no game logic computed client-side
- State machine transitions use defined valid paths; invalid transitions rejected
- Atomic state changes — `@atomic` for mutations, no partial updates
- Randomness seeded for deterministic replay
- ONUW engine stays pure Python — no Django imports

**Frontend:**
- No game logic in widgets — display server state, send actions
- No hardcoded values — use design tokens for colors, spacing, typography
- Riverpod patterns with code generation — no ad-hoc StatefulWidgets holding game state
- Dispose WebSocket connections, stream subscriptions, and controllers
- Handle loading/error states with AsyncValue patterns
- Platform-aware — works on web, iOS, Android
- No sensitive data cached in client state
